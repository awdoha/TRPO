## 0. Что нужно установить один раз

1. **.NET SDK 10** (работа проверена на версии `10.0.201`). Скачать: https://dotnet.microsoft.com/download
   Проверить установку:
   ```
   dotnet --version
   ```
2. **Visual Studio Code** + расширение **C# Dev Kit** (или обычное расширение **C#** от Microsoft) — для удобной разработки, подсветки, отладки и запуска через `F5`.
3. Для практик 3 и 5 (WinForms/WPF) — только **Windows** (кроссплатформенно эти технологии не работают).
4. Для практики 6 ничего дополнительного ставить не нужно — SQLite-провайдер EF Core работает без установки отдельного сервера БД, файл базы создаётся автоматически при первом запуске.

Открывать каждую папку `КостинДА_Nпр` в VS Code лучше **отдельно** (`File → Open Folder...`), либо открыть всю `D:\ТРПО` целиком — тогда все шесть проектов будут видны в проводнике одновременно.

## 6. Практика 6 — «Заметки» (ASP.NET Core MVC, веб-приложение)

```powershell
cd "D:\ТРПО(1)\КостинДА_6пр"
dotnet run --project Lab6\Lab6.csproj
```
В консоли появится адрес запущенного сервера, например:
```
Now listening on: http://localhost:5189
```
Откройте этот адрес в браузере. При первом запуске автоматически создастся файл базы данных `Lab6\notes.db`, применятся миграции EF Core и добавятся демонстрационные заметки/категории.

Со стартовой страницы доступны разделы «Заметки», «Категории», «Фильтрация» — там же ссылки на добавление/редактирование/удаление/статистику/экспорт в JSON.

Остановить сервер — `Ctrl+C` в терминале.

Если понадобится пересоздать базу данных с нуля — просто удалите файл `Lab6\notes.db` и запустите `dotnet run` заново (миграции применятся автоматически, база создастся заново с демоданными).

## Частые вопросы

**Приложение (3/5/6) не запускается, ошибка про SDK/TargetFramework.**
Проверьте `dotnet --version` — должна быть основная версия `10.x`. Если стоит более старая версия SDK, либо поставьте .NET 10 SDK, либо (как временное решение) в соответствующем `.csproj` замените `net10.0`/`net10.0-windows` на установленную у вас версию (например, `net8.0`/`net8.0-windows`) — весь код совместим с .NET 8+ без изменений.

**В практике 6 при запуске ошибка про EF Core / миграции.**
Убедитесь, что запускаете именно из папки `Lab6` (или указываете `--project Lab6\Lab6.csproj`) — путь к файлу базы данных относительный и создаётся рядом с проектом.

**Хочу посмотреть код в Visual Studio, а не VS Code.**
Откройте файл `.sln`/`.slnx` в корне соответствующей папки `КостинДА_Nпр` (кроме практики 2, где солюшн-файла нет — открывайте папку `пр2` целиком или сам `.csproj`).
